# Askıda İyilik — okul prototipi

Okulun eşya ve alanlarındaki sorunları bildirip gönüllülerin çözdüğü bir prototip. **Sahte verilerle çalışır**; gerçek kişi, ad ya da sorun yazma. Veriler yalnızca kendi tarayıcında durur, kimseyle paylaşılmaz.

Deneme için kayıt kodları: `AI-7K3Q`, `AI-M2XP` (her kullanışta yeni kişi açar).
